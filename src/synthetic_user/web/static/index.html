Step 1 of 4

Test setup

Define who is testing and the product. Reference data is authoritative; an optional golden set can be added to teach realistic intent and evaluation patterns.

1

Persona

Who the synthetic user is and how they ask

Sets the target for this run. Simple is strict; medium accepts simple fallback. For supported Agent scenarios, complex is strict and requires two data sources plus at least two expected tool calls; mixed allows all levels.

Used only to mimic the user's writing style. Generated questions never copy them.

The persona appears here once selected.
2

Product description

What the product does and does not do

Required
Download a product description template
Upload a product description, or configure inputs.product_path for a default.
3

Reference data

Authoritative schema, or tools, sources, workflow and rules for Agent runs

Ungrounded run. Without reference data NL2SQL answers are judged on semantic correctness only (rules and schema become N/A). Agent and golden-set runs need reference data.

Templates: Data catalog · Document collection

Usage instructions optional

How to read the reference and judge answers. Without your own, the default instructions for the reference's format are used.

The placeholder shows the default instructions for this format.

Switch reference data on to use the default or an uploaded reference.
4

Golden set

Optional SME examples used with Reference data and the other setup inputs

Optional

When uploaded, the golden set teaches realistic intent, expected-behaviour and success-criteria patterns for both NL2SQL and Agent runs. It is combined with Persona, Product and authoritative Reference data to generate new scenarios and questions; it never replaces Reference data and its questions are not replayed. Without a golden set, the pipeline generates normally from Persona, Product and Reference.

  2. 2Pending

    Generate questions

  3. 3Pending

    Ask the product

    Each question is sent to the product and the answer is recorded.

  4. 4Pending

    Evaluate answers

    Scores the answer using the run's selected evaluation profile, then derives final Accuracy.
